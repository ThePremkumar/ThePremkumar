<details>
<summary><strong>🔷 CI/CD Pipeline Flow</strong></summary>
<br/>

```
Developer ──► git push / Pull Request
      │
      ▼
GitHub (feature branch → main)
      │
      └──► GitHub Actions Trigger
                │
           ┌────┴───────────────────────────────────────────┐
           │  Stage 1 — Lint & Validate                      │
           │    terraform fmt -check                         │
           │    terraform validate                           │
           │    tflint (rule-based linting)                  │
           ├─────────────────────────────────────────────────┤
           │  Stage 2 — Plan (all PRs)                       │
           │    terraform plan -out=tfplan                   │
           │    Post plan output as PR comment               │
           │    Cost estimation (infracost)                  │
           ├─────────────────────────────────────────────────┤
           │  Stage 3 — Apply (merge to main only)           │
           │    terraform apply tfplan                       │
           │    Slack / Email notification on success/fail   │
           └────┬───────────────────────────────────────────┘
                │
                ▼
       AWS Resources Provisioned
       Drift detection scheduled every 6h via cron
```

</details>

<details>
<summary><strong>🔷 VPC Network Architecture</strong></summary>
<br/>

```
VPC: 10.0.0.0/16
├── Public Subnet  10.0.1.0/24
│       ├── Internet Gateway attached
│       ├── Application Load Balancer (port 80/443)
│       └── Bastion Host (SSH :22 — admin-IP whitelist only)
│
└── Private Subnet  10.0.2.0/24
        ├── App EC2 Instances (no direct internet access)
        └── Communicates via NAT Gateway

Security Groups (stateful):
├── sg-alb      ingress :80/:443 from 0.0.0.0/0
├── sg-bastion  ingress :22 from <admin-ip>/32 only
├── sg-web      ingress :80 from sg-alb only
└── sg-app      ingress :3000 from sg-web only

NACLs (stateless, subnet-level):
└── Blocks known malicious CIDRs — additional layer of defense-in-depth
```

</details>
